## 💻 Run the project locally

**Requirements:** Node.js 22 and pnpm.

```bash
git clone https://github.com/icse-cbse-10-12/The-ICSE-Hub.git
cd The-ICSE-Hub
pnpm install --frozen-lockfile
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).

## 🚀 Deployment

Every push to `main` triggers the workflow in `.github/workflows/deploy-pages.yml`, which builds the static site and deploys it to GitHub Pages. You can also trigger a deployment from the repository's **Actions** tab.

- **Live site:** https://icse-cbse-10-12.github.io/The-ICSE-Hub/
- **Deployment workflow:** [View GitHub Actions](https://github.com/icse-cbse-10-12/The-ICSE-Hub/actions/workflows/deploy-pages.yml)
