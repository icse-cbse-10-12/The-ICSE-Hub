- TypeScript
- Tailwind CSS
- GitHub Actions for automated deployment
- GitHub Pages for free static hosting

## Run locally

You'll need Node.js 22 and pnpm.

1. Clone the repository:
   ```bash
   git clone https://github.com/icse-cbse-10-12/The-ICSE-Hub.git
   cd The-ICSE-Hub
   ```

2. Install dependencies:
   ```bash
   pnpm install --frozen-lockfile
   ```

3. Start the development server:
   ```bash
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

## Deployment

The `.github/workflows/deploy-pages.yml` workflow builds and deploys the site to GitHub Pages when changes are pushed to `main`. You can also start a deployment manually from the repository's **Actions** tab.

The GitHub Pages build uses the repository path `/The-ICSE-Hub`. For local development, run `pnpm dev` as shown above.
